## 🧩 Troubleshooting

**The app won't open after download.**
Make sure you downloaded the correct file for your system. Try right-clicking the file and selecting "Run as administrator."

**Downloads are slow.**
This is usually due to YouTube's own limits. Try downloading one video at a time or lowering the quality setting.

**I can't find my downloaded files.**
Check your Downloads folder, or go to Settings in yt-archiver to see the current save location.

**Subtitles aren't downloading.**
Some videos don't have captions available. Try another video or check the language settings.
